Chicken Friends es un proyecto desarrollado como parte del programa Tecnólogo en Análisis y Desarrollo de Software (ADSO) del SENA.

La aplicación fue construida utilizando tecnologías de desarrollo web y backend como HTML, CSS, JavaScript, Java, Spring Boot y MySQL, integrando una arquitectura que permite la gestión de usuarios y productos mediante servicios web.

Para su despliegue y acceso en línea se utilizaron las siguientes plataformas:

-Frontend: Vercel
-Backend: Render
-Base de datos: Aiven

Este proyecto tiene como objetivo aplicar conocimientos de desarrollo full stack, integración de bases de datos, despliegue en la nube y consumo de APIs en un entorno real.
